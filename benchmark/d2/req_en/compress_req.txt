The node X receives a boolean input i and returns an integer output x. It also defines a boolean variable OK. At the initial instant, x is 0. From the next instant onward, if the previous x is less than 2, the current x is 1 minus the previous x, so it alternates between 0 and 1. Otherwise, if the previous x is not less than 2, x is 3 when i is true and 2 when i is false. OK is defined as x < 3, and the declared property requires OK to always be true.

The node Y receives boolean inputs i and clk and returns an integer output x. If clk is true, x takes the output of X(i). If clk is false, x is 0. Y also defines OK as x < 3 and declares the property that OK must always be true.
