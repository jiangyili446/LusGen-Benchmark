A node named Switch is defined, which receives three boolean inputs: Set, Reset, and Init, and returns a boolean value X. The logic for calculating X is as follows: if the Set button is pressed, X is true; if the Reset button is pressed, X is false; if neither the Set nor the Reset button is pressed, the state of X is determined by the value of the Init signal. If Init is true, X's state remains as the previous value. If Init is false, X's state remains unchanged.
