Defines a node named DownCounter that receives an integer input Time and a boolean input Restart, and returns an integer Ctr. The calculation logic for Ctr is: at the initial moment, the value of Ctr is Time. If the input Restart is true, the value of Ctr is reset to Time; if Restart is false and Ctr from the previous moment is greater than 0, the value of Ctr is decremented by 1 from the previous moment; if none of the above conditions are met, the value of Ctr remains unchanged.
