Two nodes are defined: the DownCounter node and the DownCounters node. The DownCounter node receives an integer input Time and a Boolean input Restart, and returns an integer Ctr. The initial value of Ctr is Time. The subsequent logic is as follows: if Restart is true, then the value of Ctr is set to Time; if Restart is false and the previous Ctr is greater than 0, then the value of Ctr is the previous Ctr minus one; in other cases, the value of Ctr remains the same as the previous Ctr.

The DownCounters node receives two integer inputs Time1 and Time2, and a Boolean input Restart, and returns two integers Ctr1 and Ctr2. Ctr1 is calculated by calling the DownCounter node, using Time1 and Restart as inputs; Ctr2 is calculated in the same way by calling the DownCounter node, but with inputs Time2 and Restart. Each flow instance has its own state memory.
