The node Even receives an integer input N and returns a boolean output B. B is true if and only if the current value of N modulo 2 is equal to 0. In other words, B indicates whether N is even.

The node EvensFrom receives an integer input X and returns an integer output E. E represents an increasing sequence of even numbers greater than the first value of X. At the initial instant, if X is even, E is X + 2; otherwise, E is X + 1, the first even number greater than X. At each later instant, E is the previous value of E plus 2, so it remains even and increases by 2 each step.
