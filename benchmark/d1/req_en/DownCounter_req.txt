The node DownCounter receives an integer input Time and a boolean input Restart, and returns an integer counter Ctr. At the initial instant, Ctr is Time. On later instants, if Restart is true, Ctr is reloaded with Time. Otherwise, if the previous value of Ctr is greater than 0, the current value is the previous Ctr minus 1. If the previous Ctr is not greater than 0, Ctr keeps its previous value and no longer decreases.
