The node Since receives two boolean inputs X and Y and returns a boolean output Z. Z expresses a temporal relation meaning that X has occurred since some instant while Y has continuously held. At the initial instant, Z equals X. From the second instant onward, if current X is true, Z is true. Otherwise, if current Y is true and the previous Z was true, Z remains true. If both current X and current Y are false, Z is false. Thus, Z is set to true whenever X becomes true, remains true while Y continues to hold, and is cleared when both X and Y are false.
