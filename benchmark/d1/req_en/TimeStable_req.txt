The node STABLE receives a boolean input set and an integer input delay, returns a boolean output level, and uses an internal integer variable count. The output level is true whenever count is greater than 0. When set is true, count is loaded with delay. When set is false and the previous level was true, count is decremented from the previous count. When set is false and the previous level was false, count is set to 0. Therefore, set triggers level to hold true for delay cycles; if set is triggered again during the hold, the delay is reloaded.

The node TIME_STABLE1 receives boolean inputs set and second and an integer input delay, returns a boolean output level, and uses an internal integer variable count. level is also determined by whether count is greater than 0. When set is true, count is loaded with delay. When set is false and second is true, count decrements if the previous level was true; otherwise, count is set to 0. When set is false and second is false, count keeps its current value, using 0 at the initial instant. Thus, set starts a delayed hold, but the countdown decreases only during cycles where second is true.
