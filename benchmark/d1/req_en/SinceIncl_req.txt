The node SinceIncl receives two boolean inputs X and Y and returns a boolean output Z. Z is true if and only if Y is true and one of the following holds: current X is true, or the previous value of Z was not true after the initial instant. In other words, this node describes an inclusive Since relation: Z can be true only when Y is currently true and either X holds now or Z had not already held at the previous instant. Once Z has held, if X is no longer true while Y remains true, Z becomes false.
